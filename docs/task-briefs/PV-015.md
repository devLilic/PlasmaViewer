- Status: `Completed`

## Scope and acceptance

- Ensure the production package includes `drizzle-orm`, which is statically imported by the Electron main process at startup.
- Keep Electron/Vite externalization and the main/preload/renderer security boundary intact.

- Do not change the database schema, persisted data, or the Laravel ↔ PlasmaViewer HTTP protocol.

- Run TypeScript/Vite and Electron Builder in directory mode; inspect that `drizzle-orm` is present in `app.asar`.
