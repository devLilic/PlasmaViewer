# PV-016 — Robust startup and shutdown

- Status: `In progress`
- Dependencies: PV-015 (Completed)

## Scope and acceptance

- Do not load the database module or its ORM at startup when the database feature is disabled.
- Await enabled main-module registration as part of app bootstrap and report startup failures before exiting with a non-zero status.
- If bootstrap fails after creating windows or starting the HTTP server, close those resources so an error dialog cannot leave stale PlasmaViewer processes behind.
- Stop accepting HTTP requests and close active loopback connections during normal app shutdown.
- Preserve the existing close confirmation for active output, single-instance behavior, user data, and the PlasmaViewer ↔ Plasma protocol.

## Verification

- Build TypeScript and Vite renderer/main/preload output.
- Inspect production main bundle output to confirm the disabled database module is not eagerly imported.
- Run focused lifecycle and registry tests when permitted; record tests not run and remaining manual verification.
- Verify normal close and startup failure both leave no PlasmaViewer process running.
