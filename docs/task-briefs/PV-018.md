# PV-018 — Aplicarea selecției Background cât timp este on air

- Status: `Completed`
- Dependencies: PV-017 (Completed)

## Scope and acceptance

- Când FR3 este ascuns, selectarea unui element din galeria Background actualizează doar previzualizarea.
- Când FR3 este on air, selectarea unui alt element actualizează atât previzualizarea, cât și sursa activă de pe FR3.
- Înlocuirea live păstrează media curentă vizibilă până când noua imagine sau noul clip este gata.
- Sursa selectată și cea activă sunt persistate pentru pornirea următoare.
