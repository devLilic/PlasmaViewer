# PV-014 — Icon PlasmaVu în bara nativă a ferestrei

- Status: `Completed`
- Dependențe: PV-013 (Completed)

## Scope și acceptare

- Bara nativă de titlu Windows a ferestrei PlasmaVu afișează emblema completă PlasmaVu, alături de titlul cu versiune.
- Headerul din conținutul Control și Settings nu afișează logo; navigarea rămâne centrată, iar acțiunile rămân aliniate la dreapta.
- Miniaturile imaginilor din galeria FR3 sunt reduse cu 10%, păstrând cardurile galeriei la dimensiunea curentă.
- În development, fereastra folosește iconul din `build/icon.ico`.
- În aplicația împachetată, iconul este inclus în `resources` și încărcat din acea locație, nu din faviconul rendererului sau din interiorul ASAR.
- Setarea iconului installerului și shortcuturilor rămâne compatibilă.

## Verificări

- Teste unitare pentru rezolvarea căii iconului în development și production.
- TypeScript, build Vite/Electron (unpacked dacă mediul nu permite installerul) și `git diff --check`.
- Inspectează pachetul rezultat pentru `resources/icon.ico`; verificarea vizuală a barei native rămâne manuală.

## Rezultat — 2026-10-23

Fereastra Electron folosește `build/icon.ico` în development și `resources/icon.ico` în aplicația împachetată. Electron Builder copiază iconul în afara ASAR; setarea iconului Windows pentru executabil/installer rămâne configurată. În Control și Settings logo-ul din header a fost eliminat, navigarea rămâne pe centru și acțiunile la dreapta. Miniaturile FR3 au acum 90% din lățimea anterioară, cu tile-urile galeriei păstrate.

Test focalizat pentru căile iconului: **2/2 PASS**. `npx tsc --noEmit`: **PASS**. `npx vite build`: **PASS**. Electron Builder a creat pachetul unpacked `release/pv014-icon-preview/win-unpacked`; `resources/icon.ico` este prezent (160143 bytes). A fost folosit runtime-ul Electron local; installerul NSIS nu a fost creat în această verificare. `git diff --check`: **PASS**. Lansarea cu verificare vizuală a barei native în Windows rămâne manuală.
