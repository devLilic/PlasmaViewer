# PV-013 — Updater GitHub Releases și versiune în antet

- Status: `Completed`
- Dependențe: PV-012 (Completed)

## Scope și acceptare

- Activează fluxul de actualizare din GitHub Releases prin modulul `electron-updater` existent și configurația publică GitHub configurată pentru PlasmaViewer.
- Oferă în pagina Settings o acțiune pentru verificarea actualizărilor, descărcare manuală și instalare după descărcare, folosind API-ul preload tipizat. Verificarea pornește numai la cererea utilizatorului; aplicația nu caută actualizări la lansare.
- Afișează versiunea returnată de `app.getVersion()` în titlul nativ al ferestrei principale, în formatul `PlasmaVu (1.0.2)`; în interfața renderer rămâne numai logo-ul.
- Păstrează actualizările dezactivate în development și active în build-ul production.
- Nu publică un release GitHub și nu schimbă comportamentul altor module.

## Verificări

- Teste unitare focalizate pentru configurația/activarea updaterului.
- TypeScript, build Vite/Electron și `git diff --check`.

## Rezultat — 2026-10-23

Updaterul public GitHub pentru `devLilic/PlasmaViewer` este activ în production. Buildul packaged selectează `APP_ENV=production` înainte de configurare, iar preload-ul primește aceeași setare; în development updaterul rămâne oprit. În Settings apare componenta updaterului cu verificare manuală, descărcare explicită și instalare după descărcare. Verificarea automată la pornirea aplicației este dezactivată; verificarea se execută numai când utilizatorul apasă butonul din Settings. Textul updaterului are resurse ro/en/ru.

Titlul nativ al ferestrei FR1 este `PlasmaVu (<versiune>)`, luat din `app.getVersion()`. Handlerul Electron blochează actualizarea automată a titlului din `<title>PlasmaVu</title>` și reaplică titlul cu versiunea. Rendererul păstrează numai logo-ul. `electron-updater` primește providerul și repository-ul din config prin `setFeedURL()` la pornire.

Verificări: teste focalizate auto-update/config/runtime environment/controller **44/44 PASS**; `npx vite build` pentru renderer, main și preload **PASS**; `npx tsc --noEmit` **PASS**; `git diff --check` **PASS**. Pachetul unpacked pentru verificarea titlului a fost generat în `release/pv013-titlebar-preview/win-unpacked`. `npm run build` nu a creat installerul: mediul fără rețea nu poate descărca Electron și `winCodeSign` de pe GitHub. Nu a fost publicat niciun release. Testul updaterului împotriva unui release real și instalarea shortcutului rămân verificări manuale.
