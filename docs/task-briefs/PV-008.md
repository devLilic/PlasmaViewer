# PV-008 — Preview-uri separate FR2/FR3 și galerie locală

- Status: `Completed` — varianta Windows pentru test; checklist hardware rămas explicit
- Dependențe: PV-007 (Completed)

## Scope și acceptare

Implementăm planul aprobat pentru două blocuri egale alăturate în Control: FR2 stânga, FR3 dreapta, preview-uri compacte 16:9 și scroll vertical. Preview-urile sunt limitate la 360 px lățime, aproximativ jumătate din aria preview-ului precedent. FR2 păstrează ajustările, modurile, geometria și tastele existente. FR3 are galerie persistentă locală (import/copiere, nume preluate din fișiere, miniaturi, eliminare confirmată), selecție preview separată de aplicarea live și toate ajustările FR2 comune monitorului și persistente, aplicate live. Settings păstrează defaulturile FR2 și primește selectorul comun de monitor și ordinea FR2/FR3.

Main deține fișierele și ferestrele; preload expune IPC tipizat. Migrăm imaginea/defaulturile vechi și păstrăm HTTP v1 și descriptorul defaultImage. FR2 nu mai afișează fundalul FR3. Ambele folosesc același display; implicit FR3 rămâne sub FR2 windowed și este ascuns când FR2 fullscreen este deasupra. Ordinea poate fi inversată explicit în Settings. Slider-ele nu reaplică geometria/fullscreen/z-order. Schimbarea live a imaginii păstrează stratul anterior până la încărcare. Închiderea confirmă conținutul live FR2 sau FR3; deconectarea oprește ambele.

Clarificarea utilizatorului: `hide`/„Ascunde” din plasma.test ascunde complet FR2 și lasă FR3 activ. Numai `disconnect-outputs` deconectează ambele. Câmpurile și comenzile HTTP v1 existente rămân compatibile; proiectul Laravel nu se modifică.

Clarificări vizuale aprobate: conținutul Control ocupă întreaga lățime disponibilă a ferestrei, fără limita centrală de 1500 px. Etichetele FR2/FR3 sunt în interiorul cardurilor de preview, sus-stânga. Galeria FR3 păstrează cardurile într-un singur rând cu scroll orizontal local când acestea depășesc lățimea disponibilă; numele lungi, marcajele și butoanele rămân încadrate în carduri, fără scroll orizontal al întregii pagini.

Finisări UI solicitate: panourile de ajustări FR2/FR3 pot fi pliate (deschise inițial, starea de pliere numai în sesiunea UI). Controalele windowed/fullscreen sunt sus-dreapta în cardul preview FR2, la nivelul etichetei FR2. Poziția/dimensiunile sunt imediat sub preview, înaintea ajustărilor. Galeria nu mai are redenumire în UI; eliminarea folosește un X roșu peste colțul sus-dreapta al miniaturii, cu confirmare înainte de ștergere. Eliminarea fundalului live rămâne blocată, iar comenzile și ajustările monitorului nu se schimbă.

Ultima cerință înlocuiește selectorul independent FR3: FR2 și FR3 sunt întotdeauna pe același monitor. Selectorul comun este în Settings, alături de ordinea relativă de afișare configurabilă și persistentă (z-index FR2 = 3, FR3 = 1 implicit; valori întregi 0–100, valoarea mai mare este deasupra, egalitate → FR2 deasupra). Main aplică ordinea ferestrelor native numai când se schimbă ordinea, modul, monitorul sau vizibilitatea, nu la slider-e. Comenzile HTTP v1 rămân compatibile; selectarea unui display prin API-ul FR2/FR3 actualizează monitorul comun. Migrarea preferă vechiul display FR2, cu fallback la cel FR3/monitor disponibil. Când FR2 fullscreen este deasupra, FR3 se ascunde temporar; dacă ordinea este inversată explicit, FR3 rămâne deasupra.

Ajustarea din taste folosește acum 10 px implicit și 50 px cu Shift, atât pentru deplasare cu săgețile, cât și pentru redimensionare cu Ctrl+săgeți. Escape și regulile pentru fullscreen/focus/controale editabile se păstrează.

Galeria trebuie restaurată după repornirea aplicației, nu numai la navigarea în UI. Confirmăm persistența într-o a doua instanță Electron cu același profil temporar de test. Numele afișat lângă logo și în bara de titlu devine PlasmaVu; identitatea aplicației, directorul userData și numele executabilului rămân neschimbate pentru a nu pierde galeria/setările existente.

## Pași pentru testarea variantei

1. Închide versiunea curentă PlasmaViewer, apoi pornește `release/dual-preview-test/win-unpacked/PlasmaViewer.exe`. Portul/tokenul de integrare rămân cele configurate pentru plasma.test.
2. FR2: afișează o știre din plasma.test, verifică ajustările, windowed/fullscreen din colțul sus-dreapta al preview-ului, 16:9 și poziția/dimensiunile imediat sub preview. Tastele mută cu 10 px implicit și 50 px cu Shift; Ctrl+săgeți redimensionează cu aceiași pași. „Ascunde” trebuie să ascundă FR2 și să lase FR3 disponibil. Pliază panourile FR2/FR3 prin apăsarea titlului sau a săgeții și confirmă că ajustările și imaginea live nu se schimbă.
3. FR3: adaugă fișiere locale cu numele emisiunilor, selectează alt fundal și confirmă că se schimbă numai preview-ul. Apasă „Afișează” pentru a-l aplica pe ecran. Marcajul „Aplicat” indică ultimul fundal aplicat; „LIVE” apare numai pentru preview-ul identic cu fundalul efectiv vizibil. Cu mai multe imagini verifică derularea orizontală numai în galerie; cu nume lungi verifică încadrarea textelor. Redenumirea nu mai este disponibilă în galerie. Apasă X-ul roșu pe o miniatură neactivă, anulează și verifică păstrarea imaginii și selecției; repetă și confirmă eliminarea. X-ul fundalului live este dezactivat. Fișierul original nu se șterge.
4. Reglează FR3 și verifică efectul live fără modificarea FR2. Repornește și confirmă păstrarea galeriei, selecției, fundalului aplicat, monitorului comun, ordinii și ajustărilor FR3. Lângă logo și în bara de titlu trebuie să apară PlasmaVu.
5. În Settings selectează monitorul comun pentru FR2/FR3. Implicit FR2 z-index 3 este deasupra FR3 z-index 1. Inversează ordinea și verifică FR3 deasupra; pentru valori egale FR2 rămâne deasupra. FR3 este temporar ascuns în fullscreen FR2 numai când FR2 este deasupra. Comută monitorul comun, apoi scoate/reconectează un monitor și verifică fallbackul fără separarea FR2/FR3.
6. Verifică lipsa flash-urilor, „Deconectează” cu numai FR3 live și confirmarea de închidere cu FR2 sau numai FR3 activ.

Prima migrare păstrează `viewer-settings.pre-dual-preview.json` în userData. Pentru revenire la setările anterioare, închide aplicația și restaurează această copie; fișierele sursă ale imaginilor importate rămân intacte. Versiunea aplicației rămâne 1.0.1 și nu se publică un release.

Verificarea automată Electron se rulează după build cu `npx electron scripts/verify-dual-preview.mjs`: profil temporar, port 47839, ferestre ascunse și randare offscreen. Pentru verificarea unei reporniri reale, rulează apoi aceeași comandă cu `--verify-restart-profile="<profile>"`, unde `profile` este cel din `results.json`. Sunt acceptate numai profilurile temporare generate de acest test; galeria și setările nu se recreează în a doua execuție. Capturile și rezultatele `results.json`/`restart-results.json` sunt în `release/dual-preview-test/verification/`. Aceasta nu înlocuiește verificarea hardware.
